# Web Scraping with EDA

This project demonstrates how to **scrape product data from an e-commerce website** using `requests` and `BeautifulSoup`, then perform **basic Exploratory Data Analysis (EDA)** on the extracted dataset.  

---

## Features
- Scrapes product details (name, price, description, stock, categories, and tags).  
- Stores the data in a structured **Pandas DataFrame**.  
- Performs **EDA** to explore distributions, trends, and summary statistics.  
- Provides clean, reproducible **Jupyter Notebook** workflow.  

---

## Tech Stack
- **Python 3**
- **Libraries Used**:
  - `requests`
  - `beautifulsoup4`
  - `pandas`
  - `matplotlib`
  - `seaborn`
